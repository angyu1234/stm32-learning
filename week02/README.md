## D8 · 指针 + 函数指针表

2h · 目标：理解函数指针在驱动里的真实用法

- `arr[i]` 等价于 `*(arr + i)`；数组名多数场景退化为指针，**但 `sizeof(arr)` 和 `&arr` 是例外**（面试爱考）
- `int *p[10]`（10 个指针）vs `int (*p)[10]`（指向含 10 个 int 的数组的指针）。看声明的诀窍：从变量名开始，先右后左，括号优先

**函数指针表（重点）** —— 驱动框架和状态机的核心写法：

```c
typedef void (*Handler)(void);
Handler handlers[] = {handle_idle, handle_sample, handle_upload};
handlers[state]();          /* 用状态值直接索引，避免一长串 switch-case */
```

好处：加一种状态只需往数组加一项，不用改调用逻辑（开闭原则，面试官很吃这个）。

**动手**：做 **ex10**；自己写一个三层状态机（空闲 → 采集 → 上报）；用指针遍历二维数组体会「行指针」

**验收**：能区分 `int *p[10]` 和 `int (*p)[10]` / 能写函数指针类型定义并放进数组调用 / 状态机跑通

## D9 · 手写 strcpy / memmove

2h · 目标：理解重叠内存这个经典陷阱

```c
char *my_strcpy(char *dst, const char *src)
{
    char *ret = dst;
    while ((*dst++ = *src++) != '\0')      /* 连 '\0' 一起拷贝 */
        ;
    return ret;                             /* 返回原始 dst，支持链式调用 */
}
```

**memcpy vs memmove（核心考点）**：

- `memcpy` **不处理内存重叠**，重叠时行为未定义
- `memmove` 处理重叠：目标在源之前 → 正向拷；目标在源之后 → 从后往前拷
- 判断：`if (dst < src || dst >= src + n)` 正向，否则反向

**动手**：做 **ex8 / ex9**；自己构造重叠场景验证：

```c
char buf[] = "abcdef";
my_memmove(buf + 2, buf, 4);    /* 正确结果是 "ababcd" */
```

用 memcpy 的逻辑写这里会出错 —— **亲眼看到 bug 才记得住**。

**面试高频**：
- `strcpy` 和 `memcpy` 的区别？→ ① 遇 `\0` 停止 vs 按字节数 ② 只处理字符串 vs 任意内存 ③ 不处理重叠 vs memmove 处理
- `sizeof` 和 `strlen`？→ 编译期运算符（含 `\0`）vs 运行期函数（数到 `\0`，不含）

**验收**：my_strcpy 通过（含返回原指针）/ my_memmove 重叠场景正确

## D14 · 时钟树 + GPIO 点亮 LED + M1 验收

3h · 目标：第一块板子跑起来，两周收官

**一、理解时钟树（1h，别跳过）**

所有外设都要先开时钟才能用，**外设不工作 80% 的原因是忘了开时钟** —— 新手第一大坑。

看懂三条线：**HCLK（AHB）→ PCLK1（APB1 低速外设）→ PCLK2（APB2 高速外设）**。
CubeMX 的 Clock Configuration 页面能直观看到分频关系。知道你的芯片主频（F103C8 通常 72MHz），以及 UART 波特率怎么从 PCLK 算出来。

验收标准：**合上资料能画出时钟树三条主线**。

**二、GPIO 点亮 LED（1.5h）**

八种模式重点四个：推挽输出（LED）、开漏输出（I²C）、上拉输入（按键）、浮空输入。

- 接线：LED 串联 **220Ω 电阻**接在 GPIO 与 GND 之间（**不串电阻会烧 GPIO**）
- 下载：ST-Link 接 SWD（SWDIO / SWCLK / 3V3 / GND 四根线），CubeIDE → Run → Debug
- 闪烁：`HAL_GPIO_TogglePin()` + `HAL_Delay(500)`
- **进阶（推荐）**：不用 HAL，直接 `GPIOx->BSRR = (1U << pin);` —— 把 D4 学的位操作用上，这是知识闭环的时刻
- 用**逻辑分析仪抓一次波形**，看实际翻转周期是否与代码一致。从第一天就养成「眼见为实」的习惯

**三、录演示视频 + M1 验收（0.5h）**

- 演示型视频（≤1 分钟）：LED 闪烁实物画面 + 一句说明 → 存 `assets/视频/`
- 素材入库（**第一张照片、第一段视频、第一条数据**）
- 更新 `PROGRESS.md`，`git push`

**D14 讲解视频要回答的问题**：

1. 为什么必须先使能 RCC 的 IOPC 时钟？
2. PC13 为什么配置在 `CRH` 而不是 `CRL`？对应哪几位？
3. 那 4 个配置位（MODE / CNF）的值是怎么算出来的？
4. 为什么推荐用 `BSRR` 而不是直接写 `ODR`？
