# 寄存器速查表

> 这是整个学习过程中**最值钱的一份文件**。每学一个外设就往里加一段。
> 面试前 10 分钟过一遍，平时写代码也不用反复翻 1100 页的参考手册。

来源：STM32F103x8/xB Reference Manual (RM0008) · 芯片：STM32F103C8T6

---

## 一、存储器映射（RM0008 第 2 章）

| 区域 | 起始地址 | 说明 |
|---|---|---|
| Flash | `0x0800 0000` | 程序存放处，F103C8T6 有 64KB |
| SRAM | `0x2000 0000` | 运行时的栈/堆/全局变量，20KB |
| 外设寄存器 | `0x4000 0000` | 所有外设寄存器都映射在这一段 |
| 内核外设 | `0xE000 0000` | NVIC、SysTick 等（Cortex-M3 私有） |

## 二、总线划分

| 总线 | 挂载的外设 | 最高频率（72MHz 主频时） |
|---|---|---|
| AHB | 内核、DMA、SRAM、Flash 接口 | 72 MHz |
| APB2 | GPIOA~E、AFIO、USART1、SPI1、ADC1/2、TIM1、TIM8 | 72 MHz |
| APB1 | TIM2~7、USART2/3、I2C1/2、SPI2、CAN、USB、RTC、WWDG、IWDG、PWR、BKP | 36 MHz |

**记忆要点**：GPIO 挂 APB2（`RCC_APB2ENR`），所以开 GPIO 时钟要操作 `RCC_APB2ENR`，不是 `RCC_APB1ENR`。

---

## 三、RCC 时钟相关

| 寄存器 | 地址 | 作用 |
|---|---|---|
| `RCC_CR` | `0x4002 1000` | 时钟控制：HSION / HSERDY / PLLON / PLLRDY |
| `RCC_CFGR` | `0x4002 1004` | 时钟配置：PLL 倍频、AHB/APB 分频、系统时钟源选择 |
| `RCC_APB2ENR` | `0x4002 1018` | APB2 外设时钟使能 |
| `RCC_APB1ENR` | `0x4002 101C` | APB1 外设时钟使能 |
| `RCC_AHBENR` | `0x4002 1014` | AHB 外设时钟使能（DMA、SRAM、FLITF） |

### RCC_APB2ENR 常用位

| 位 | 名称 | 外设 |
|---|---|---|
| bit 0 | AFIOEN | 复用功能 IO |
| bit 2 | IOPAEN | GPIOA |
| bit 3 | IOPBEN | GPIOB |
| bit 4 | IOPCEN | **GPIOC**（蓝板板载 LED 在 PC13） |
| bit 5 | IOPDEN | GPIOD |
| bit 6 | IOPEEN | GPIOE |
| bit 9 | ADC1EN | ADC1 |
| bit 12 | SPI1EN | SPI1 |
| bit 14 | USART1EN | USART1 |

### RCC_APB1ENR 常用位

| 位 | 名称 | 外设 |
|---|---|---|
| bit 0 | TIM2EN | TIM2 |
| bit 1 | TIM3EN | TIM3 |
| bit 21 | I2C1EN | I2C1 |
| bit 22 | I2C2EN | I2C2 |
| bit 14 | SPI2EN | SPI2 |
| bit 17 | USART2EN | USART2 |
| bit 25 | CANEN | CAN |

## 四、GPIO（RM0008 第 9 章）

### 寄存器列表（以 GPIOx 表示，A~E 基址如下）

| 端口 | 基址 |
|---|---|
| GPIOA | `0x4001 0800` |
| GPIOB | `0x4001 0C00` |
| GPIOC | `0x4001 1000` |
| GPIOD | `0x4001 1400` |
| GPIOE | `0x4001 1800` |

| 寄存器 | 偏移 | 地址（以 C 为例） | 作用 |
|---|---|---|---|
| `GPIOx_CRL` | 0x00 | `0x4001 1000` | 配置 Px0 ~ Px7 |
| `GPIOx_CRH` | 0x04 | `0x4001 1004` | **配置 Px8 ~ Px15** |
| `GPIOx_IDR` | 0x08 | `0x4001 1008` | 输入数据（只读） |
| `GPIOx_ODR` | 0x0C | `0x4001 100C` | 输出数据 |
| `GPIOx_BSRR` | 0x10 | `0x4001 1010` | **位设置/清除（原子操作）** |
| `GPIOx_BRR` | 0x14 | `0x4001 1014` | 位清除（只写） |
| `GPIOx_LCKR` | 0x18 | `0x4001 1018` | 配置锁定 |

### CRL / CRH 的位定义

每个引脚占 **4 位**：`CNF[1:0]` + `MODE[1:0]`

- `CRL` 中：引脚 n（0~7）对应 bit `4n` ~ `4n+3`
- `CRH` 中：引脚 n（8~15）对应 bit `4(n-8)` ~ `4(n-8)+3`

| MODE[1:0] | 含义 |
|---|---|
| 00 | 输入模式 |
| 01 | 输出模式，最大 10MHz |
| 10 | 输出模式，最大 2MHz |
| 11 | 输出模式，最大 50MHz |

| CNF[1:0] | 输入模式时 | 输出模式时 |
|---|---|---|
| 00 | 模拟输入 | 通用推挽输出 |
| 01 | 浮空输入 | 通用开漏输出 |
| 10 | 上拉/下拉输入 | 复用推挽输出 |
| 11 | 保留 | 复用开漏输出 |

> 上拉还是下拉，由 `ODR` 对应位的值决定（1 = 上拉，0 = 下拉）。

### 引脚计算示例：PC13 配置为通用推挽输出、2MHz

```
偏移 = (13 - 8) * 4 = 20
CRH &= ~(0xF << 20);          /* 先清零这 4 位 */
CRH |=  (0x2 << 20);          /* MODE = 10 (2MHz)，CNF = 00 (通用推挽) */
```

### BSRR 的用法（重点）

- 低 16 位（bit0~15）：写 1 → 对应引脚**置高**，写 0 → 无影响
- 高 16 位（bit16~31）：写 1 → 对应引脚**置低**，写 0 → 无影响

```c
GPIOC->BSRR = (1U << 13);          /* PC13 置高 */
GPIOC->BSRR = (1U << (13 + 16));   /* PC13 置低 */
```

**为什么用 BSRR 不用 ODR**：写 ODR 是「读-改-写」三步，中途被中断打断可能导致状态错误；BSRR 是单次写入、硬件原子操作，且写 0 不影响其它位。
