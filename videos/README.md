## 讲解型视频的自检清单

录完先自己回看一遍，确认：

- [ ] 全程不卡壳（卡了就重录，或停下来搞懂再录）
- [ ] 对着代码或纸笔讲，不是念代码
- [ ] 把当天指定的每个问题都答到了
- [ ] 语速正常，能被一个不懂的人听懂
- [ ] 视频链接可用（换个浏览器/退出登录验证一次）

**讲解型视频是整个学习机制里最有价值的一环。** 讲不顺的地方就是你还没真懂的地方 —— 这比任何自测题都准。
