# docs/img —— 图片与框图

存放系统框图、波形截图、调试器截图、编译输出截图等。

## 命名规范

```
w<周>-d<天>-<主题>.png

示例：
w01-d01-mcu-block.png        # D1 的 MCU 结构框图
w01-d02-toolchain.png        # D2 的编译成功 + 设备识别截图
w01-d05-debug.png            # D5 调试器画面
w02-d08-pointer.png          # D8 指针输出 / 调试器画面
w02-d11-map.png              # D11 的 map 文件 / Memory Usage
```

## 为什么截图也算交付物

「我配置成功了」和「这是配置成功的证据」是两件事。截图是**给自己留的证据链** —— 三个月后你回头看，能立刻想起当时的状态；面试时如果聊到具体问题，也有东西可以展示。

另外，把图放进 Git 会让仓库更「活」，README 里引用几张关键截图，说服力远高于纯文字。
