# 素材库

> 论文、专利、竞赛作品、答辩 PPT 需要的素材高度重叠。
> **每完成一个功能就立刻存：一张照片 + 一段视频 + 一条数据。**
> 等到要交的时候再去补就补不回来了（实验数据当时没记，三个月后只能重做实验）。

## 目录

| 子目录 | 存什么 | 是否进 Git |
|---|---|---|
| `照片/` | 硬件接线、实物运行、逻辑分析仪波形 | ❌ 大文件，忽略 |
| `视频/` | 每个里程碑的功能演示（30~60 秒） | ❌ 大文件，忽略 |
| `图/` | 系统框图、流程图、时序图（draw.io 导出 SVG） | ✅ |
| `数据/` | 每次测试的原始 CSV + 结论 | ✅（关键的几条） |
| `文档/` | 项目提案、创新点表述、导师反馈 | ✅ |

## 命名规范

```
照片/  W02-D14_接线全景.jpg
视频/  W02-D14_LED闪烁演示.mp4
图/    系统框图_v1.svg
数据/  20261027_功耗测试_原始.csv
文档/  导师反馈_20261019.md
```

统一：`W<周次>-D<日期>_<内容>.<扩展名>`，图和数据另加版本号。
